## 部署指南

### GitHub仓库创建
1. 在GitHub上创建一个新的仓库，命名为 `username.github.io`（其中username是你的GitHub用户名）
2. 将本地代码推送到该仓库

### Cloudflare Pages部署
1. 登录Cloudflare账号
2. 进入Pages服务
3. 点击"Create a project"
4. 选择连接到GitHub仓库
5. 选择你创建的仓库
6. 配置构建设置：
   - 构建命令：`None`（因为是纯静态网站）
   - 构建输出目录：`/`
7. 点击"Save and Deploy"
8. 部署完成后，你将获得一个Cloudflare Pages提供的域名

### 自定义域名（可选）
1. 在Cloudflare Pages项目设置中，添加自定义域名
2. 按照提示完成DNS配置
